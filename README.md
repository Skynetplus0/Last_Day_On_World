# Last Day on World 🧟‍♂️🏰

**Last Day on World** is a 3D tower defense game developed using **Unity** by a team of seven developers.  
The game is set in a post-apocalyptic world where players must defend their base against incoming zombie waves by strategically placing different types of towers.

The project features:
- Multiple enemy wave systems
- Resource management (coins & score)
- Different tower types with unique behaviors
- Three distinct maps with increasing difficulty
- Real-time combat and strategic placement mechanics

---

## 🎮 Project Overview

In *Last Day on World*, players:
- Defend their base from zombie invasions
- Earn coins by killing enemies
- Build and strategically place towers
- Survive increasingly difficult waves
- Play on **three different maps**, each offering unique layouts and challenges

The game focuses on **strategy, positioning, and resource management**.

## ⚙️ Setup & Installation

### Prerequisites
- **Unity Hub**
- **Unity Editor** (recommended version: *Unity 2022 LTS or later*)
- Git

### Installation Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/LastDayOnWorld.git
2. Open Unity Hub
- Click Open Project
- Select the cloned project folder
3.Load the Project
-Wait for Unity to import assets and packages
-Resolve any missing package prompts automatically
4. Open the Main Scene
Navigate to:
Assets/Scenes/MainMenu.unity
or
Assets/Scenes/Level1.unity
5.Press Play ▶️
-------Deployment / Build Guide

1.Open File → Build Settings

2.Add required scenes:
-MainMenu
-Level1
-Level2
-Level3
3.Select target platform (Android,PC, Mac & Linux Standalone)
4.Click Build
5.Run the generated executable

🕹 Usage Instructions
-Start Game: From the main menu
-Place Towers: Select a tower and place it on valid areas
-Earn Coins: Kill zombies
-Defend Base: Prevent enemies from reaching the base
-Game Over: Occurs when base health reaches zero
-Restart: Available from the Game Over screen
